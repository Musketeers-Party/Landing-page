# Musketeers-Party — AboutUs

Organization landing page + projects showcase site.

## What you get

- `index.html` — organization landing page: hero, mission, featured project (Nép), full project grid, subscribe CTA.
- `projects.html` — projects showcase page with category filters (All / Mobile / Server / Tools) and per-project detail modal.
- Styling is co-located in each file's `<style>` block (pure single-file portability); optional separate `css/style.css` can be linked.
- `js/main.js` (optional separate) — vanilla JS for navigation, reveal animations, modal, subscribe.

## Stack

- Pure HTML
- Tailwind CSS via CDN (`https://cdn.tailwindcss.com`)
- Vanilla JavaScript (no frameworks)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
cd AboutUs
python3 -m http.server 8000
# then visit http://localhost:8000
```
